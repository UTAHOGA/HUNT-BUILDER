# Architecture Decision Records

These records preserve accepted Hunt Builder decisions across people, Codex tasks, and model changes.

## Rules

- An accepted record is not edited to reverse its decision.
- A changed decision gets a new ADR that names the record it supersedes.
- `governance/engine-authority.json` states what is active now.
- `docs/CURRENT_STATE.md` summarizes the current operational state.
- `WORK_LOG.md` records history but does not overrule an accepted ADR.
- Tyler's explicit current instruction can authorize a new decision.

## Statuses

- `Accepted`: active architectural decision.
- `Superseded`: replaced by a later ADR.
- `Proposed`: not yet authoritative.
- `Rejected`: considered and not adopted.
