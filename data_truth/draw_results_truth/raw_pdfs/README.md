# CWMU parent-PDF subset library

These PDFs are derived CWMU page subsets split out of larger Utah DWR parent PDFs. The raw parent PDFs stay under data_truth/draw_results_truth/raw_pdfs; these sidecars live here so they do not inflate raw source file counts.

Naming convention:
- cwmu_draw_*.pdf: draw-results parent source
- cwmu_points_*.pdf: points summary parent source
- cwmu_quota_*.pdf: permit quota parent source
- cwmu_guide_*.pdf: guidebook/application parent source
- cwmu_source_*.pdf: comprehensive/manual source package
- *__review_*.pdf: hash conflict retained for manual review
